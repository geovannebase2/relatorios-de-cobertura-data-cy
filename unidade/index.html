Metodologia

Contagem obtida via git grep -oE '(data-cy|dataCy)[A-Za-z]*[[:space:]]*=' <rev> -- <pasta>, comparando o estado do código de 17/08/2026 (data de acesso ao repositório) com o estado atual da branch — que já contém a primeira leva de instrumentação mais o complemento de "acelerar cadastro" feito depois. O padrão captura tanto o atributo DOM literal data-cy= quanto qualquer prop React da família dataCy*= (ex.: dataCyView=) sendo efetivamente atribuída — declarações em PropTypes e leituras de prop sem atribuição não entram na contagem.

Blocos com 0 no "antes" (Pessoa relacionada/Veículo e Acelerar cadastro) são marcados como Novo em vez de percentual — cobertura criada do zero não tem uma base para calcular crescimento relativo.

Componentes compartilhados entram como linha própria, separada do total dos 6 blocos: eles também são reaproveitados por outros módulos (Cliente, Fornecedor, Condomínio) fora do escopo deste relatório, então somá-los ao total principal misturaria o ganho de Unidade com o de outras telas.

Esse número mede atributos inseridos no DOM, refletindo o quanto de código de instrumentação foi de fato adicionado ao repositório desde 17/08 — não é a mesma unidade de medida de um "item mapeado" em um levantamento de gaps elemento a elemento.

Metodologia

Contagem obtida via git grep -oE '(data-cy|dataCy)[A-Za-z0-9]*[[:space:]]*=' <rev> -- <pasta>, comparando origin/master (antes) com o estado atual do código (depois). O padrão captura tanto o atributo DOM literal data-cy= quanto qualquer prop React da família dataCy*= (ex.: dataCyView=, dataCyBotaoSalvar=) sendo efetivamente atribuída — declarações em PropTypes e leituras de prop sem atribuição não entram na contagem.

Escopo restrito às 5 features do módulo Despesa mapeadas no artifact original de gaps (Contas a Pagar, EFD-Reinf, Fornecedor, Imposto, Cheques). A rota /v2/group-pay ficou de fora por decisão explícita anterior — é uma aplicação separada, fora deste repositório.

Componentes compartilhados (FormLinhaDigitavel, Tabs, FormSelectCreatable, FormMonthPickerRequired, FormaPagamento, FileAnnex, SeletorClassePlanoContas, CurrencyAliquota) também ganharam props dataCy novas para viabilizar parte desses ganhos — por isso entram no relatório como linha própria, separada do total das 5 features: como esses componentes também são reaproveitados por telas fora do módulo Despesa, somá-los ao total principal inflaria o número sem representar só Despesa.

Esse número mede atributos inseridos no DOM, não é a mesma unidade de medida de um "item mapeado" em um levantamento de gaps elemento a elemento (470 itens no artifact original — que agrupa, por exemplo, um ActionPanel inteiro como 1 item mesmo quando vira 3 props dataCy separadas na implementação).
